# AIO-Tools
All In One Tools adalah kumpulan tool praktis untuk pekerjaan sehari-hari: mengolah teks, mengurus file, menghitung, mengonversi satuan, dan banyak lagi. Semuanya gratis dan berjalan di browser Anda.

Prinsip kami
Gratis dan tanpa login. Tidak ada akun, tidak ada paywall, tidak ada batas pemakaian.
Berjalan di perangkat Anda. Isi yang Anda proses tidak dikirim ke server. Tool yang membutuhkan pemrosesan file (gambar, PDF) bekerja sepenuhnya di browser.
Tanpa iklan dan pelacakan. Tidak ada skrip iklan, tidak ada analitik pihak ketiga, tidak ada profil pengguna.
Tanpa klaim berlebihan. Jika ada tool yang belum selesai atau punya batasan, kami akan katakan apa adanya.
Teknologi
Situs ini dibangun dengan HTML, CSS, dan JavaScript vanilla — tanpa framework, tanpa build step. Library tambahan (jika diperlukan untuk tool tertentu) dimuat dari CDN publik hanya saat tool tersebut dibuka. Font dimuat dari Bunny Fonts. Hosting statis berada di Cloudflare Pages.

Lisensi & atribusi
Ikon UI: SVG buatan sendiri, bebas pakai.
Font: Bricolage Grotesque, Instrument Sans, JetBrains Mono, dan Fraunces — dilisensikan di bawah SIL Open Font License, dimuat dari fonts.bunny.net.
Library CDN opsional (jsPDF, pdf-lib, QRCode.js, Chart.js, marked.js, CryptoJS) — mengikuti lisensi masing-masing proyek.
Tidak ada foto stok. Tidak ada emoji di antarmuka.
