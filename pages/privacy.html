Kebijakan Privasi

Terakhir diperbarui: 8 November 2026

Ringkasan singkat. All In One Tools tidak memiliki server aplikasi. Semua pemrosesan terjadi di browser Anda. Kami tidak mengumpulkan data pribadi, tidak memasang iklan, dan tidak memasang cookie pelacakan.

1. Data yang tidak kami kumpulkan

  • Isi teks, gambar, PDF, atau file apa pun yang Anda proses di tool.
  • Alamat email, nama, nomor telepon, atau data pribadi lain.
  • Riwayat penelusuran Anda di luar situs ini.
  • Alamat IP untuk tujuan profil atau iklan.

2. Data yang disimpan di perangkat Anda

Kami menggunakan localStorage browser untuk menyimpan preferensi. Data ini tidak pernah dikirim ke server mana pun.

KunciIsiFungsi

Anda dapat menghapus semua data ini kapan saja dari tombol di bagian bawah halaman, atau lewat pengaturan browser.

3. Layanan pihak ketiga

Situs ini memuat beberapa sumber daya dari pihak ketiga agar bisa berjalan:

LayananTujuanData yang mungkin terlihat
Bunny Fonts (fonts.bunny.net) Memuat font tampilan (Bricolage Grotesque, Instrument Sans, JetBrains Mono, Fraunces). Alamat IP & User-Agent standar yang dikirim setiap browser saat meminta file. Bunny Fonts tidak menetapkan cookie pelacak.
Cloudflare Pages (hosting) Menyajikan file statis situs. Log akses standar (IP, waktu, URL) di sisi hosting, dikelola Cloudflare sesuai kebijakan mereka.
CDN library (jsDelivr / cdnjs) Memuat library opsional (jsPDF, pdf-lib, QRCode.js, Chart.js, marked.js, CryptoJS) — hanya saat tool terkait dibuka. Alamat IP & User-Agent standar. Tidak ada library yang dimuat pada halaman yang tidak memerlukannya.

Kami tidak menggunakan Google Analytics, Facebook Pixel, atau layanan periklanan apa pun.

4. Dasar hukum & hak Anda

Kami mematuhi prinsip yang selaras dengan UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP) Indonesia serta GDPR Uni Eropa untuk pengunjung dari wilayah tersebut. Karena kami tidak mengumpulkan data pribadi apa pun di server, praktisnya:

  • Tidak ada data pribadi yang perlu Anda minta, ubah, atau hapus dari kami.
  • Semua data yang tersimpan berada di perangkat Anda dan dapat Anda hapus sendiri kapan saja.
  • Jika Anda tetap ingin mengajukan permintaan terkait data (misalnya mengonfirmasi bahwa kami tidak menyimpan data Anda), silakan hubungi kami lewat halaman Kontak.

5. Anak-anak

Situs ini dirancang untuk pengguna berusia 13 tahun ke atas. Kami tidak dengan sengaja mengumpulkan data dari anak di bawah 13 tahun (atau batas usia digital setempat). Jika Anda orang tua/wali dan mengetahui anak Anda menggunakan situs ini, Anda dapat menghapus semua data lokal dari perangkat tersebut dengan tombol hapus di bawah.

6. Keamanan

Karena seluruh pemrosesan dilakukan di browser Anda dan tidak ada data yang dikirim ke server, permukaan risiko jauh lebih kecil dibanding tool berbasis server. Akses ke situs melalui HTTPS. Untuk data yang sangat sensitif (misalnya dokumen rahasia), tetap disarankan bekerja secara offline setelah halaman dimuat.

7. Perubahan kebijakan

Kebijakan ini dapat diperbarui seiring penambahan fitur. Tanggal "Terakhir diperbarui" di atas akan berubah jika ada perubahan material. Kami tidak akan menambahkan pelacakan tanpa memberi tahu lebih dulu lewat banner persetujuan.
